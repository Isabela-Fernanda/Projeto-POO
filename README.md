# RPG

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

## Descrição

Sistema de RPG por turnos inspirado em Tormenta20, desenvolvido em TypeScript utilizando conceitos de Programação Orientada a Objetos.

## Funcionalidades

- Criação de personagens
- Sistema de combate
- Classes jogáveis
- Inventário
- Equipamentos
- Habilidades

## Tecnologias

- TypeScript
- Node.js
